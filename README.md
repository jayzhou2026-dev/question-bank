# 变电运维刷题工具

这是一个静态网页刷题工具，适合部署到 GitHub Pages、Cloudflare Pages 或任意静态网站空间。题库数据来自当前目录中的 Excel 文件，已转换为 `questions.json`。

## 本地预览

在本目录启动静态网页服务后，用浏览器打开服务地址即可预览。

如果要给 iPad 临时测试，需要电脑和 iPad 在同一个 WiFi 下，并用 iPad 打开电脑的局域网地址。

## 公网发布

推荐发布到 GitHub Pages 或 Cloudflare Pages。需要上传这些文件：

- `index.html`
- `styles.css`
- `app.js`
- `questions.json`

发布完成后，把公网网址发给使用者，她用 iPad 浏览器打开即可刷题。

## 学习记录

学习记录保存在当前浏览器本地，包括已做题、正确率、错题、收藏和考试记录。设置页支持导出和导入学习记录，换设备前建议先导出备份。

## 注意事项

- 题库随网页公开发布，知道网址的人理论上都能访问。
- 当前 Excel 的详解字段为空，网页只显示正确答案。
- 第一版不包含账号登录和多设备自动同步。
